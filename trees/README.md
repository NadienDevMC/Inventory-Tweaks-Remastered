# Modded tree files for Inventory Tweaks Revived (Minecraft 1.21.1)

Each `.tree` file adds the items of one mod to the item tree. Copy the ones you want into `config/InvTweaks/trees/`. The file name is the mod id. Format and merge rules: see the `readme.txt` that the mod writes in that folder.

All files use `treeVersion="1.21.1"` and only `id`, `tag` and `mergePrevious`. Unless noted, the ids were checked against the item models of the mod jars for 1.21.1.
